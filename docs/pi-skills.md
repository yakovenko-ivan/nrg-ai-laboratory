# NRG Pi Skills

Project skills encode reusable procedural and scientific know-how. They do not replace `AGENTS.md` or trusted `nrg_*` tool validation.

Current project skills:

- `nrg-study-analysis` — generic scientific-study workflow from histories to structured results and report.
- `nrg-campaign-design` — hypothesis-driven campaign design and parameter semantics.
- `nrg-0d-ignition-analysis` — domain conventions for homogeneous constant-volume ignition analysis.
- `nrg-plot-data` — dense Tecplot/gnuplot export convention using `nrg_analysis.plot_data`.

Layering rule:

`AGENTS.md` = global policy and behavioral boundaries.

`Pi skills` = reusable procedural/scientific knowledge.

`nrg_* tools / nrg_analysis` = trusted executable capabilities and invariants.

`study/analyze.py` = hypothesis-specific implementation.
